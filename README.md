# LifeLink-Organ-Donation-Management-System
LifeLink is a web-based platform designed to streamline organ donation and recipient matching using a Neo4j database. The system enables donors to register their details, recipients to request organs, and an intelligent matching system to connect compatible donors and recipients based on blood type and organ compatibility.
